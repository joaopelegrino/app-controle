> **Nota:** Este conteúdo reflete o projeto quando ainda era voltado para **aprendizado individual** (B2C), antes do pivô para **produto B2B corporativo** (Novembro 2025).

### Visão Original (B2C)

"Plataforma B2B de treinamento técnico corporativo é uma plataforma educacional interativa que capacita desenvolvedores a dominar tecnologias modernas através de aprendizado estruturado, gamificado e prático."

**Persona Original:**
- Nome: "João, o Desenvolvedor Iniciante"
- Idade: 20-35 anos
- Contexto: Estudo autodidata, ambiente WSL2
- Frustrações: Falta de estrutura, conteúdo disperso

**Features B2C:**
- Sistema de conquistas (badges, gamificação pessoal)
- Progresso visual individual
- Flash cards 3D para memorização
- PWA para estudo offline
- Dark mode para estudar à noite

### Evolução para B2B (Novembro 2025)

**O que mudou:**
1. **Público:** Indivíduo → Empresas de tecnologia
2. **Problema:** "Sem estrutura de estudo" → "R$180k/ano desperdiçados em Udemy Business"
3. **Solução:** Gamificação pessoal → Multi-tenancy + SSO + Analytics corporativo
4. **Pricing:** Implicitamente gratuito → R$500/mês flat (até 100 usuários)
5. **Roadmap:** Dark mode, PWA → Multi-tenant, SSO, API RESTful

**O que se manteve:**
- Stack React + Vite + Tailwind
- 5 sistemas integrados (C, Rust, Bash, VSCode, Claude Code)
- Flash cards 3D
- Caderno de Notas
- Nomenclatura ÉPICO 12 (Hub > Curso > Aula)
