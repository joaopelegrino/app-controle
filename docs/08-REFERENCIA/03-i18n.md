# Internacionalizacao (i18n)

O app-controle suporta multiplos idiomas via [react-i18next](https://react.i18next.com).

## Idiomas Suportados

| Codigo | Idioma | Status |
|--------|--------|--------|
| pt-BR | Portugues (Brasil) | Completo |
| en-US | English | Completo |
| es-ES | Espanol | Completo |

## Arquitetura

### Estrutura de Arquivos

```
public/locales/

│   ├── common.json      # Geral (app, nav, buttons)
```

| Namespace | Conteudo | Strings |
|-----------|----------|---------|

| dashboard | user, admin, instructor, executive, common, courses | ~155 |
| hub | specialists, catalog, reviews, revenue, marketplace | ~50 |

**Total: ~355 strings por idioma**

## Configuracao

### src/i18n/config.js

```javascript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';
import Backend from 'i18next-http-backend';

i18n
  .use(Backend)
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    fallbackLng: 'pt-BR',
    supportedLngs: ['pt-BR', 'en-US', 'es-ES'],
    ns: ['common', 'auth', 'errors', 'dashboard', 'hub'],
    defaultNS: 'common',
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json',
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },
    interpolation: {
      escapeValue: false,
    },
  });

export default i18n;
```

## Uso em Componentes

### Hook useTranslation

```jsx
import { useTranslation } from 'react-i18next';

function LoginView() {
  const { t } = useTranslation(['auth', 'common']);

  return (
    <div>
      <h1>{t('common:app.name')}</h1>
      <h2>{t('auth:login.title')}</h2>
      <button>{t('auth:login.submitButton')}</button>
    </div>
  );
}
```

### Com Interpolacao

```jsx
// JSON
{
  "welcome": "Ola, {{name}}!"
}

// Componente
<p>{t('welcome', { name: user.name })}</p>
// Output: "Ola, Maria!"
```

### Com Pluralizacao

```jsx
// JSON
{
  "items_zero": "Nenhum item",
  "items_one": "{{count}} item",
  "items_other": "{{count}} itens"
}

// Componente
<p>{t('items', { count: items.length })}</p>
```

### Hook useLanguage

```jsx
import { useLanguage } from '../i18n';

function LanguageInfo() {
  const {
    currentCode,    // 'pt-BR'
    currentName,    // 'Portugues'
    currentFlag,    // 'BR'
    changeLanguage, // (code) => void
    isRTL,          // false
  } = useLanguage();

  return (
    <button onClick={() => changeLanguage('en-US')}>
      Switch to English
    </button>
  );
}
```

## LanguageSelector

O componente `LanguageSelector` oferece 3 variantes:

### Dropdown

```jsx
<LanguageSelector variant="dropdown" />
```

Select com bandeiras e nomes completos.

### Buttons

```jsx
<LanguageSelector variant="buttons" />
```

Botoes lado a lado com bandeiras. Usado no login.

### Minimal

```jsx
<LanguageSelector variant="minimal" />
```

Apenas codigo do idioma (PT | EN | ES).

## Adicionar Novo Idioma

### 1. Criar Pasta

```sh
mkdir -p public/locales/fr-FR
```

### 2. Copiar Arquivos

```sh
cp public/locales/en-US/*.json public/locales/fr-FR/
```

### 3. Traduzir

Edite cada arquivo JSON com as traducoes.

### 4. Registrar

Em `src/i18n/config.js`:

```javascript
supportedLngs: ['pt-BR', 'en-US', 'es-ES', 'fr-FR'],
```

### 5. Adicionar Seletor

Em `LanguageSelector.jsx`, adicione a opcao.

## Adicionar Novas Strings

### 1. Adicionar ao JSON

```json
// public/locales/pt-BR/common.json
{
  "newSection": {
    "newKey": "Novo texto"
  }
}
```

### 2. Adicionar em Todos os Idiomas

Repita para `en-US` e `es-ES`.

### 3. Usar no Componente

```jsx
<p>{t('common:newSection.newKey')}</p>
```

## Boas Praticas

### Organizacao

- Use namespaces para separar contextos
- Agrupe por funcionalidade, nao por componente
- Mantenha chaves semanticas

### Nomenclatura

```json
// BOM
{
  "user": {
    "create": "Criar usuario",
    "edit": "Editar usuario",
    "delete": "Excluir usuario"
  }
}

// RUIM
{
  "userCreateButton": "...",
  "userEditButton": "...",
  "userDeleteButton": "..."
}
```

### Interpolacao

```json
// BOM - Flexivel para diferentes linguas
{
  "greeting": "Ola, {{name}}!"
}

// RUIM - Fragmentado
{
  "greetingStart": "Ola, ",
  "greetingEnd": "!"
}
```

### Pluralizacao

```json
// Use as convencoes do i18next
{
  "items_zero": "Nenhum item",
  "items_one": "{{count}} item",
  "items_other": "{{count}} itens"
}
```

## Debugging

### Ver Idioma Atual

```javascript
console.log(i18n.language);
```

### Ver Traducoes Carregadas

```javascript
console.log(i18n.store.data);
```

### Forcar Idioma

```javascript
i18n.changeLanguage('en-US');
```

### Chave Faltando

Se uma chave nao existe, mostra a propria chave:

```
auth:login.unknownKey
```

Para debug, ative `debug: true` na config.

## Testes

### Testar Traducoes

```javascript
import i18n from '../i18n/config';

describe('Translations', () => {
  beforeEach(() => {
    i18n.changeLanguage('pt-BR');
  });

  it('should have login title', () => {
    expect(i18n.t('auth:login.title')).toBe('Acesse sua conta');
  });

  it('should interpolate name', () => {
    expect(i18n.t('common:greeting', { name: 'Maria' }))
      .toBe('Ola, Maria!');
  });
});
```

### Testar Componente

```jsx
import { render, screen } from '@testing-library/react';
import { I18nextProvider } from 'react-i18next';
import i18n from '../i18n/config';

test('renders login in Portuguese', () => {
  i18n.changeLanguage('pt-BR');
  render(
    <I18nextProvider i18n={i18n}>
      <LoginView />
    </I18nextProvider>
  );
  expect(screen.getByText('Acesse sua conta')).toBeInTheDocument();
});
```
