# ⚡ Quick Start - MCP Chrome DevTools

**5 minutos para começar a usar automação de navegador com Claude Code**

---

## 🎯 Comandos Essenciais

### 1. Listar Páginas
```
Você: Liste as páginas abertas no Chrome
```

### 2. Navegar
```
Você: Navegue para http://localhost:3000
```

### 3. Screenshot
```
Você: Tire um screenshot da página
```

### 4. Inspecionar Console
```
Você: Verifique erros no console
```

### 5. Interagir
```
Você: Clique no botão "Rust"
```

## 📋 Checklist Pré-uso

- [ ] Chrome for Testing instalado
- [ ] Servidor Vite rodando (`npm run dev`)
- [ ] MCP habilitado (`.claude/settings.local.json`)
- [ ] `.mcp.json` configurado

---

## 🚨 Problemas Comuns

**MCP não carrega?**
→ Reinicie Claude Code

**Chrome não abre?**
→ Verifique `--executable-path` no `.mcp.json`

**Página em branco?**
→ Confirme que servidor Vite está rodando
