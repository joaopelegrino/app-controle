## 📦 Tarefas NocoDB (7)

### `mise nocodb:setup`
**O que faz:**
- Copia `.env.nocodb.example` → `.env.nocodb` (se não existir)
- Carrega variáveis de ambiente
- Inicia `docker-compose.nocodb.yml`
- Aguarda serviços iniciarem
- Mostra status e URL de acesso

**Quando usar:** Primeira vez configurando NocoDB

```bash
mise nocodb:setup
# ✅ Setup completo!
# 📍 NocoDB: http://localhost:8080
# 📧 Email: admin@ultrathink.com
# 🔐 Senha: UltraThink@Admin2026!
```

---

### `mise nocodb:start`
**O que faz:** Inicia containers NocoDB (PostgreSQL + NocoDB)

**Quando usar:** Toda vez que precisar do backend

```bash
mise nocodb:start
# ✅ NocoDB iniciado: http://localhost:8080
```

---

### `mise nocodb:stop`
**O que faz:** Para todos os containers NocoDB

```bash
mise nocodb:stop
# ✅ NocoDB parado
```

---

### `mise nocodb:restart`
**O que faz:** Reinicia containers (útil para aplicar mudanças)

```bash
mise nocodb:restart
# ✅ NocoDB reiniciado
```

---

### `mise nocodb:logs`
**O que faz:** Mostra logs em tempo real (útil para debug)

```bash
mise nocodb:logs
# [logs do NocoDB em tempo real]
# Ctrl+C para sair
```

---

### `mise nocodb:health`
**O que faz:**
- Verifica se containers estão rodando
- Verifica se PostgreSQL responde
- Verifica se NocoDB está acessível
- Conta quantos usuários estão no banco

```bash
mise nocodb:health
# 🔍 Verificando NocoDB...
# ✅ Containers rodando
# ✅ PostgreSQL: OK
# ✅ NocoDB: OK (http://localhost:8080)
# ✅ Dados seed: 7 usuários carregados
```

---

### `mise nocodb:reset`
**O que faz:** ⚠️ **DELETA TODOS OS DADOS** e recria banco

**Quando usar:** Resetar para estado inicial (dados seed)

```bash
mise nocodb:reset
# ⚠️  Isso vai DELETAR todos os dados. Continuar? (y/N) y
# 🗑️  Resetando banco...
# ✅ Banco resetado (dados seed recarregados)
```

## 🎭 Tarefas Testes E2E (3)

### `mise e2e:ui`
**O que faz:**
- Verifica se dev server está rodando (http://localhost:3000)
- Verifica se NocoDB está rodando (http://localhost:8080)
- Abre Playwright UI para testes interativos

**Quando usar:** Desenvolver e debugar testes E2E

**Pré-requisitos:**
```bash
# Terminal 1: Dev server
mise dev

# Terminal 2: NocoDB
mise nocodb:start

# Terminal 3: Testes
mise e2e:ui
```

---

### `mise e2e:headless`
**O que faz:** Executa testes E2E sem interface (para CI/CD)

**Quando usar:** Rodar testes automaticamente

```bash
mise e2e:headless
# 🎭 Executando testes E2E...
# [resultados dos testes]
```

---

### `mise e2e:install`
**O que faz:** Instala browsers do Playwright (Chromium, Firefox, WebKit)

**Quando usar:** Primeira vez ou após atualizar Playwright

```bash
mise e2e:install
# Downloading Chromium...
# Downloading Firefox...
# Downloading WebKit...
```

## 🔄 Workflows Completos (4)

### `mise setup`
**O que faz:**
1. Instala ferramentas (Bun, Node, Python)
2. Instala dependências (bun install)
3. Setup NocoDB (copiar .env + docker-compose up)
4. Instala browsers Playwright

**Quando usar:** Primeira vez clonando o projeto

```bash
mise setup
# 🚀 Setup completo do projeto...
# 📦 1/3: Instalando dependências...
# 🐳 2/3: Setup NocoDB...
# 🎭 3/3: Instalando browsers Playwright...
# ✅ Setup completo!
```

---

### `mise check`
**O que faz:**
- Verifica ferramentas instaladas (Bun, Node, Docker)
- Verifica se dev server está rodando
- Verifica se NocoDB está rodando
- Verifica se dependências estão instaladas

**Quando usar:** Diagnóstico rápido

```bash
mise check
# 🔍 Verificando ambiente...
# 📦 Ferramentas:
#   Bun: 1.3.3
#   Node: 24.11.1
#   Docker: 24.0.6
# 🔥 Dev server:
#   ✅ Rodando (http://localhost:3000)
# 🐳 NocoDB:
#   ✅ Containers rodando
#   ✅ PostgreSQL: OK
#   ✅ NocoDB: OK
# 🧪 Testes:
#   ✅ Dependências instaladas
```

---

### `mise test:all`
**O que faz:**
1. ESLint (verifica código)
2. Testes unitários (Vitest)
3. Testes E2E (Playwright) - se serviços estiverem rodando

**Quando usar:** Antes de commit/PR

```bash
mise test:all
# 🧪 Executando todos os testes...
# 📝 1/3: ESLint...
# 🧪 2/3: Testes unitários...
# 🎭 3/3: Testes E2E...
# ✅ Todos os testes passaram!
```

---

### `mise full-stack`
**O que faz:**
1. Inicia NocoDB (docker-compose)
2. Inicia dev server (bun run dev) em segundo plano
3. Mostra URLs e PID

**Quando usar:** Desenvolvimento full-stack rápido

```bash
mise full-stack
# 🚀 Iniciando full-stack...
# 🐳 Iniciando PostgreSQL + NocoDB...
# 🔥 Iniciando dev server...
# ✅ Full-stack rodando!
# 📍 Frontend: http://localhost:3000
# 📍 NocoDB: http://localhost:8080
# PID do dev server: 12345

# Para parar:
# Ctrl+C (para dev server)
# mise nocodb:stop (para NocoDB)
```

## ⚠️ Avisos

1. **Docker é obrigatório:** Todas as tarefas `nocodb:*` precisam de Docker

2. **Portas 3000 e 8080:** Dev server e NocoDB usam essas portas

3. **Dados resetados:** `mise nocodb:reset` deleta TUDO

4. **Browsers Playwright:** Ocupam ~500MB (baixar com `mise e2e:install`)
