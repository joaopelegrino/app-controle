## ⚠️ Importante: Requer mise activate

Para hooks funcionarem, você precisa ter no **~/.zshrc** (ou ~/.bashrc):

```bash
eval "$(mise activate zsh)"
```

### Verificar se está configurado:

```bash
grep -q "mise activate" ~/.zshrc && echo "✅ OK" || echo "❌ FALTA"
```

### Se faltar, adicionar:

```bash
echo 'eval "$(mise activate zsh)"' >> ~/.zshrc
source ~/.zshrc
```
